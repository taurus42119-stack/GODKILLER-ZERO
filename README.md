Stop AI vibe-coding before it ships. One click. Cursor · Claude · Antigravity.

**Windows · MIT · [@kayvins.th](https://www.instagram.com/kayvins.th)**

## Use

1. Download [`godkiller-zero-windows-x86_64.zip`](https://github.com/taurus42119-stack/GODKILLER-ZERO/releases/latest)
2. Run `GodkillerZero.exe`
3. Click **SHIELD**

Or:

```powershell
irm https://raw.githubusercontent.com/taurus42119-stack/GODKILLER-ZERO/main/install.ps1 | iex
```

## Build

Needs Rust + .NET SDK 9+

```powershell
.\build.ps1
```

Output: `publish\GodkillerZero.exe`, `publish\godkiller-console.exe`
