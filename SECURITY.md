# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The GODKILLER ZERO team takes the security and integrity of developer environments seriously.

If you discover a security vulnerability within this repository or associated binaries:

1. **Do not disclose publicly.** Please do not open public GitHub issues for security vulnerabilities.
2. **Report via GitHub Security Advisory:** Use the "Report a vulnerability" button under the [Security tab](https://github.com/taurus42119-stack/godkiller-zero/security/advisories/new).
3. Alternatively, report directly to the maintainer via GitHub profile contact.

### What to Include

- Detailed steps to reproduce the vulnerability.
- Proof of Concept (PoC) or sample prompt/code triggering the defect.
- Target platform and version tested.
- Potential impact or blast radius of the issue.

### Response Timeline

- **Initial Acknowledgement:** Within 48 hours.
- **Triage & Remediation Plan:** Within 7 business days.
- **Public Disclosure:** Coordinated after a patched release is published.
